\chapter{Digital Twin for Real-Time Protection Audit}
\label{ch:digital_twin}

\section{Introduction}
\label{sec:ch7_intro}

The protection algorithms of Chapters~\ref{ch:line_diff}--\ref{ch:microgrid}
require real-time knowledge of the IBR current ratio $\kibr$, the line
impedance $\Zline$, and the fault location parameter $\alpha$.
In practice, $\kibr$ varies continuously with solar irradiance and
generation curtailment, $\Zline$ drifts with conductor temperature,
and $\alpha$ is the primary objective of the fault localisation algorithm.
None of these quantities is directly measurable from a single relay terminal.

This chapter proposes a \emph{non-blocking digital twin} (DT) architecture
that runs a real-time Extended Kalman Filter (EKF) to jointly estimate
the state vector $\mathbf{x} = [\kibr,\; \Zline,\; \alpha]^\top$ from
the available current measurements, delivering:
\begin{itemize}
\item \textbf{C10}: The non-blocking DT architecture for real-time
      protection audit (Section~\ref{sec:ch7_architecture}).
\item \textbf{C11}: EKF joint estimation of $(\kibr, \Zline, \alpha)$
      from the current ratio alone (Section~\ref{sec:ch7_ekf}).
\end{itemize}

\section{Digital Twin Architecture}
\label{sec:ch7_architecture}

\subsection{Non-Blocking Design Principle}

A \emph{blocking} digital twin is one that halts the primary relay
decision until the DT computation completes. This is unacceptable for
protection systems, where the primary trip must issue within
$\leq 5$~ms of fault detection. The \textbf{non-blocking} design principle
requires that:
\begin{enumerate}
\item The DT state estimate $\hat{\mathbf{x}}(t)$ is \emph{always available}
      at the moment the relay logic is evaluated.
\item The DT update cycle runs asynchronously at 20~ms (one power cycle),
      publishing new estimates to a shared memory register.
\item The relay logic reads from the shared memory register at its
      50~$\mu$s sampling rate; reads and writes are atomic (no race condition).
\end{enumerate}
This is analogous to a \emph{shadow register} pattern in real-time
embedded systems.

\subsection{Information Inputs}

The DT receives the following inputs:
\begin{itemize}
\item Local current phasor $\phasor{I}_A$ at 20~ms intervals (50 Hz rate).
\item Remote current phasor $\phasor{I}_B$ via GOOSE (4~ms latency;
      time-stamped to 1~$\mu$s precision by IEEE~1588 PTP).
\item Pre-fault line impedance nominal $\Zline^0$ from the settings database.
\item Ambient temperature $T_\mathrm{amb}$ from a sensor (for cable impedance correction).
\end{itemize}

\subsection{Information Outputs}

The DT publishes to the relay protection logic:
\begin{itemize}
\item $\hat{\kibr}$: real-time IBR current ratio estimate.
\item $\hat{\Zline}$: corrected line impedance estimate.
\item $\hat{\alpha}$: estimated fault location (available only during fault).
\item $\sigma_{\kibr}^2$, $\sigma_{\Zline}^2$, $\sigma_\alpha^2$: posterior
      variances for confidence-weighted relay decisions.
\end{itemize}

\section{Extended Kalman Filter for State Estimation}
\label{sec:ch7_ekf}

\subsection{System State Model}

The DT state vector at time step $k$ is:
\begin{equation}
  \mathbf{x}_k = \begin{bmatrix}\kibr(k) \\ \Zline(k) \\ \alpha(k)\end{bmatrix}
  \label{eq:ch7_state}
\end{equation}
The state transition model is a random walk with process noise:
\begin{equation}
  \mathbf{x}_{k+1} = \mathbf{x}_k + \mathbf{w}_k, \qquad
  \mathbf{w}_k \sim \mathcal{N}(\mathbf{0}, \mathbf{Q})
  \label{eq:ch7_state_transition}
\end{equation}
where the process noise covariance is:
\begin{equation}
  \mathbf{Q} = \mathrm{diag}\!\left[\sigma_{k_\mathrm{ibr}}^2,\;
    \sigma_{Z_L}^2,\; \sigma_\alpha^2\right]
  = \mathrm{diag}[0.001^2,\; 0.0002^2,\; 0.005^2]
  \label{eq:ch7_Q}
\end{equation}
These values are set from the expected drift rates:
$\kibr$ changes at $\approx 0.001$~pu/cycle with generation modulation;
$\Zline$ changes at $\approx 0.02\%$/cycle with temperature;
$\alpha$ is constant between fault events and changes instantaneously.

\subsection{Measurement Model}

The measurements available to the EKF are the current ratio:
\begin{equation}
  y_k = \frac{|\phasor{I}_B(k)|}{|\phasor{I}_A(k)|} = \frac{\kibr I_r}{I_A}
  \label{eq:ch7_measurement}
\end{equation}
and the phase-angle difference:
\begin{equation}
  \phi_k = \angle\!\left(\frac{\phasor{I}_B(k)}{\phasor{I}_A(k)}\right)
  \label{eq:ch7_phase_meas}
\end{equation}
These two scalars form the measurement vector $\mathbf{y}_k = [y_k, \phi_k]^\top$.

The nonlinear measurement model is:
\begin{equation}
  \mathbf{y}_k = h(\mathbf{x}_k) + \mathbf{v}_k
  \label{eq:ch7_obs_model}
\end{equation}
where $\mathbf{v}_k \sim \mathcal{N}(\mathbf{0}, \mathbf{R})$ and:
\begin{align}
  h_1(\mathbf{x}) &= \frac{\kibr I_r}{|V_0|/(Z_S + \alpha \Zline)}
  = \frac{\kibr I_r (|Z_S + \alpha \Zline|)}{|V_0|}
  \label{eq:ch7_h1} \\
  h_2(\mathbf{x}) &= \angle\!\left(-\frac{Z_S + \alpha \Zline}{Z_\mathrm{IBR}}\right)
  + \phi_\mathrm{IBR}
  \label{eq:ch7_h2}
\end{align}
The measurement noise covariance is:
\begin{equation}
  \mathbf{R} = \mathrm{diag}[\sigma_y^2, \sigma_\phi^2]
  = \mathrm{diag}[0.005^2,\; (2°)^2]
  \label{eq:ch7_R}
\end{equation}
corresponding to CT measurement accuracy of 0.5\% and PLL phase error of 2°.

\subsection{EKF Algorithm}

The EKF linearises the nonlinear measurement model at each step:
\begin{equation}
  \mathbf{H}_k = \left.\frac{\partial h}{\partial \mathbf{x}}\right|_{\mathbf{x} = \hat{\mathbf{x}}_k^-}
  \label{eq:ch7_jacobian}
\end{equation}
The Jacobian elements are:
\begin{align}
  \frac{\partial h_1}{\partial \kibr} &= \frac{I_r |\hat{Z}_S + \hat{\alpha}\hat{\Zline}|}{|V_0|}
  \label{eq:ch7_jac11} \\
  \frac{\partial h_1}{\partial \Zline} &= \frac{\hat{\kibr} I_r \hat{\alpha}
    \mathrm{Re}[(Z_S + \hat{\alpha}\hat{\Zline})/|Z_S + \hat{\alpha}\hat{\Zline}|]}{|V_0|}
  \label{eq:ch7_jac12} \\
  \frac{\partial h_1}{\partial \alpha} &= \frac{\hat{\kibr} I_r \hat{\Zline}
    \mathrm{Re}[(Z_S + \hat{\alpha}\hat{\Zline})/|Z_S + \hat{\alpha}\hat{\Zline}|]}{|V_0|}
  \label{eq:ch7_jac13}
\end{align}
and similarly for $h_2$ (see Appendix~\ref{app:proofs}, Proof~\ref{proof:ekf_jacobian}).

Algorithm~\ref{alg:ch7_ekf} states the EKF update cycle.

\begin{algorithm}[htbp]
\caption{EKF State Estimation (C11)}
\label{alg:ch7_ekf}
\begin{algorithmic}[1]
\Require Prior estimate $\hat{\mathbf{x}}^-_{k}$, covariance $\mathbf{P}^-_k$
\Require New measurements $\mathbf{y}_k = [y_k, \phi_k]^\top$
\Ensure Posterior estimate $\hat{\mathbf{x}}_k$, covariance $\mathbf{P}_k$
\State Compute Jacobian: $\mathbf{H}_k \leftarrow \partial h/\partial \mathbf{x}|_{\hat{\mathbf{x}}^-_k}$
\State Innovation: $\tilde{\mathbf{y}}_k \leftarrow \mathbf{y}_k - h(\hat{\mathbf{x}}^-_k)$
\State Innovation covariance: $\mathbf{S}_k \leftarrow \mathbf{H}_k \mathbf{P}^-_k \mathbf{H}_k^\top + \mathbf{R}$
\State Kalman gain: $\mathbf{K}_k \leftarrow \mathbf{P}^-_k \mathbf{H}_k^\top \mathbf{S}_k^{-1}$
\State Update estimate: $\hat{\mathbf{x}}_k \leftarrow \hat{\mathbf{x}}^-_k + \mathbf{K}_k \tilde{\mathbf{y}}_k$
\State Update covariance: $\mathbf{P}_k \leftarrow (\mathbf{I} - \mathbf{K}_k \mathbf{H}_k)\mathbf{P}^-_k$
\State Clip: $\hat{\kibr} \leftarrow \mathrm{clip}(\hat{\kibr}, 0, 2)$, etc.
\State \textbf{Predict}: $\hat{\mathbf{x}}^-_{k+1} \leftarrow \hat{\mathbf{x}}_k$, \; $\mathbf{P}^-_{k+1} \leftarrow \mathbf{P}_k + \mathbf{Q}$
\end{algorithmic}
\end{algorithm}

\subsection{Observability Analysis}
\label{sec:ch7_observability}

\begin{proposition}[EKF Local Observability]
\label{prop:ch7_observability}
The system defined by the measurement model \eqref{eq:ch7_obs_model}
is locally observable at the operating point $(\hat{\kibr}, \hat{\Zline}, \hat{\alpha})$
if the following rank condition holds:
\begin{equation}
  \mathrm{rank}(\mathbf{H}_k) = n_x = 3
  \label{eq:ch7_observability}
\end{equation}
This condition is satisfied when the fault location $\alpha \neq 0$
(non-zero fault location), $\kibr \neq 0$ (non-zero IBR contribution),
and $\Zline \neq 0$ (non-zero line impedance).
\end{proposition}

\begin{proof}
See Appendix~\ref{app:proofs}, Proof~\ref{proof:ekf_observability}.
The proof shows that the Jacobian determinant:
\begin{equation}
  \det(\mathbf{H}_k) = \kibr I_r \hat{\alpha} \hat{\Zline}
    \cdot f(\hat{\mathbf{x}}_k) \neq 0
    \quad\forall\; \kibr, \alpha, \Zline > 0
  \label{eq:ch7_det}
\end{equation}
\end{proof}

The observability condition fails at $\alpha = 0$ (relay end fault):
the fault location cannot be estimated from local measurements alone
because $Z_S + 0 \cdot \Zline = Z_S$ does not depend on $\Zline$ or $\alpha$.
This is a fundamental physical limitation: two-ended voltage phasors
are required for $\alpha$ observability at $\alpha = 0$. In the SAMBP
system, PMU measurements from the adjacent bus fill this gap
(Chapter~\ref{ch:centralised}, Section~\ref{sec:ch9_wapc}).

\section{EKF Performance Analysis}
\label{sec:ch7_ekf_results}

\subsection{Steady-State RMSE Bounds}

The steady-state EKF posterior variance is bounded by the Cramér-Rao
lower bound (CRLB):
\begin{equation}
  P_k^\infty \geq \left(\mathbf{H}^\top \mathbf{R}^{-1} \mathbf{H}
    + \mathbf{Q}^{-1}\right)^{-1}
  \label{eq:ch7_crlb}
\end{equation}
Substituting the nominal operating point $(\kibr = 0.3, \Zline = 0.1 + 0.08\jj,
\alpha = 0.5)$ gives:
\begin{align}
  \mathrm{RMSE}_{\kibr} &= \sqrt{P_{11}^\infty} \leq 0.024\;\mathrm{pu}
  \label{eq:ch7_rmse_kibr} \\
  \mathrm{RMSE}_{Z_L} &= \sqrt{P_{22}^\infty} \leq 0.5\%\;\mathrm{of}\;|\Zline|
  \label{eq:ch7_rmse_zl} \\
  \mathrm{RMSE}_\alpha &= \sqrt{P_{33}^\infty} \leq 1.1\%\;\mathrm{of}\;\ell
  \label{eq:ch7_ekf_alpha}
\end{align}
For a 10~km line, $\mathrm{RMSE}_\alpha \leq 110$~m, well within the
zone boundary tolerance of $\pm 500$~m.

\subsection{Convergence Time}

The EKF converges from the initial estimate to within the CRLB bound
in approximately $N_\mathrm{conv}$ cycles:
\begin{equation}
  N_\mathrm{conv} = \frac{\ln(\mathbf{P}_0/\mathbf{P}^\infty)}
    {-\ln\!\left(1 - \mathrm{tr}(\mathbf{K}\mathbf{H})\right)}
  \approx 15\;\mathrm{cycles} = 300\;\mathrm{ms}
  \label{eq:ch7_conv}
\end{equation}
at 50~Hz. This is acceptable for the protection audit use case (the DT
state is used for offline relay settings optimisation, not for the
primary trip decision).

\section{Digital Twin Validation}
\label{sec:ch7_validation}

The DT is validated against the 6th-order Park $dq$ truth model
(Section~\ref{sec:ch2_park6}). Validation criteria:
\begin{enumerate}
\item Voltage waveform agreement: RMS error $\leq 0.5\%$ for $t \in [0, 150]$~ms.
\item Current waveform agreement: RMS error $\leq 1.0\%$ for $t \in [0, 150]$~ms.
\item $\kibr$ estimation: RMSE $\leq 0.024$~pu.
\item Fault location estimation: RMSE $\leq 1.1\%$ for $\alpha \in [0.1, 0.9]$.
\end{enumerate}

The validation study (SAMBP~TR-45) confirms all four criteria for
$t \leq 150$~ms. For $t > 150$~ms, the reduced model deviates from the
Park truth model when AVR dynamics become significant—the range of
validity for the DT is therefore $[0, 150]$~ms, covering the entire
protection decision window.

\section{Summary}
\label{sec:ch7_summary}

This chapter has developed the non-blocking digital twin for real-time
protection audit:
\begin{enumerate}
\item \textbf{Non-blocking architecture (C10):} Shadow register pattern
      decouples EKF update (20~ms cycle) from relay logic (50~$\mu$s cycle),
      ensuring the DT never delays a primary trip decision.
\item \textbf{EKF state estimation (C11):} Joint estimation of
      $(\kibr, \Zline, \alpha)$ from the current ratio achieves
      RMSE $\leq 0.024$~pu, $\leq 0.5\%$, $\leq 1.1\%$ respectively,
      bounded by the derived CRLB.
\item \textbf{Observability:} The system is locally observable for
      $\kibr, \alpha, \Zline > 0$; the unobservable case
      ($\alpha = 0$) is resolved by the WAPC PMU measurements.
\item \textbf{Validation:} Agreement with the 6th-order Park truth model
      within 1\% RMS for the first 150~ms post-fault.
\end{enumerate}
