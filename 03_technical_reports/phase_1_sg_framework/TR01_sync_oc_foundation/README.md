## Compilation

### Full report (recommended)
```bash
cd report/
make report      # runs pdflatex × 3 + bibtex
```

### Standalone figures only
```bash
make figures     # compiles each fig_*.tex independently
```

### Convert figures to 300 dpi PNG (for journal submission)
```bash
make fig_png     # requires poppler-utils (pdftoppm)
```

### Manual compilation
```bash
pdflatex main_report
bibtex   main_report
pdflatex main_report
pdflatex main_report
```

## Report Structure

| Section | Content |
|---------|---------|
| 1. Introduction | Background, problem statement, literature review, contributions |
| 2. Physical System Model | Generator equations, Stage-1 synthesis, all forward model equations |
| 3. Reduced-Order Fault Model | 6-parameter model, DC continuity constraint, parameter bounds |
| 4. Inverse Parameter Estimation | LS formulation, phase-A residual, LM/TRF algorithm, two-pass strategy, identifiability |
| 5. Confidence Scoring | Four sub-scores (sr, sc, sb, sp), weights, adaptation gate |
| 6. Relay Model & Adaptive Mapping | IEC Very-Inverse equations, sliding RMS, pickup/TMS mapping, bounded update law |
| 7. Numerical Results | All three study cases, tables with placeholders for figures |
| 8. Discussion | Iss interpretation, Phase B/C residuals, computational feasibility |
| 9. Conclusions | Key findings, limitations, future work roadmap |
| Appendices | IEC curve constants, default guesses, analytical Jacobian |

## Result Placeholders

Sections marked `\RESULT{...}` in the LaTeX source are placeholders for
figures generated by `plot_milestone1.py`. To insert actual results:

1. Run `python plot_milestone1.py` from the `sambp_sync_oc/` directory
2. Copy the relevant PNGs from `outputs/plots/milestone1/` to `report/figures/`
3. Replace each `\RESULT{...}` block with `\includegraphics[width=\textwidth]{figures/fig_name.png}`
