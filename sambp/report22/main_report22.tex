\section{Background and Motivation}
\label{sec:background}

\subsection{IBR current limiting and 87L sensitivity}

Inverter-based resources (IBRs) protect their power electronics by limiting
output current during faults to 1.0--1.2\,pu~\cite{Plet2011,Hooshyar2019}.
In a microgrid or weak-grid connection where the IBR dominates the fault
current supply, the positive-sequence differential current
$|\Delta I_1|$ seen by the 87L element may be as low as the IBR current
limit ($k_{\rm ibr}$):
\begin{equation}
  |\Delta I_1| \approx k_{\rm ibr} \qquad (0.08\text{--}0.20\,\text{pu})
\end{equation}
When $k_{\rm ibr} < I_{1,\rm threshold} = 0.12$\,pu, the 87L element
\emph{misses} the fault.  For the study parametric model ($I_{\rm natural}
= 0.30$\,pu), this occurs for $k_{\rm ibr} < 0.12$\,pu (five of seven test
levels).

\subsection{Negative-sequence behaviour of IBRs}

The positive-sequence current limiter of a standard grid-following IBR
limits the $d$-axis (active) and $q$-axis (reactive) reference in
positive-sequence coordinates~\cite{ENTSO_RfG}.  Critically, this limiter
operates on positive-sequence quantities only:
\begin{itemize}
  \item \textbf{Positive sequence} ($I_1$): limited to $k_{\rm ibr}$ pu.
  \item \textbf{Negative sequence} ($I_2$): governed by the fault sequence
        network, \emph{not} directly limited by the same control loop.
\end{itemize}

For a single-line-to-ground (SLG) fault, the symmetrical component
network forces $I_1 = I_2 = I_0$ at the fault point.  The
negative-sequence differential is therefore:
\begin{equation}
  |\Delta I_2| = \alpha_{\rm asym} \times I_{\rm fault,natural}
  \label{eq:I2}
\end{equation}
where $\alpha_{\rm asym}$ is the fault asymmetry factor ($\approx 0.4$
for a representative midline SLG on the study network).  For
$I_{\rm natural} = 0.30$\,pu:
\begin{equation}
  |\Delta I_2|_{\rm SLG} = 0.40 \times 0.30 = 0.12\,\text{pu}
  \qquad (> I_{2,\rm threshold} = 0.06\,\text{pu})
\end{equation}

The 87LN negative-sequence differential therefore detects all SLG faults
regardless of IBR current limiting, as long as the fault creates a
measurable sequence current.

\subsection{Sequence network illustration}

Figure~\ref{fig:seqnet} shows the positive- and negative-sequence networks
for a SLG fault.  The key difference: the positive-sequence source at the
IBR terminal is current-limited; the negative-sequence source is not (for
standard grid-following control).

\section{87LN Measurement Algorithm}
\label{sec:algorithm}

\subsection{Symmetrical component extraction}

From the three-phase differential waveforms $i_{{\rm diff},a}$,
$i_{{\rm diff},b}$, $i_{{\rm diff},c}$, the negative-sequence phasor is:
\begin{equation}
  \underline{I}_2 = \frac{1}{3}
    \bigl(\underline{I}_a + a^2\underline{I}_b + a\,\underline{I}_c\bigr)
  \qquad a = e^{j2\pi/3}
  \label{eq:I2_phasor}
\end{equation}
where $\underline{I}_\phi$ denotes the fundamental phasor extracted by DFT
from phase $\phi$.

\subsection{Combined trip logic}

\begin{equation}
  \text{TRIP} = \underbrace{(|\Delta I_1| \geq I_{1,\rm thr})}_{\text{87L}}
              \;\vee\;
              \underbrace{(|\Delta I_2| \geq I_{2,\rm thr})}_{\text{87LN}}
  \label{eq:trip}
\end{equation}

Threshold settings (study network):
\begin{itemize}
  \item $I_{1,\rm thr} = 0.12$\,pu (unchanged from TR-15/TR-17)
  \item $I_{2,\rm thr} = 0.06$\,pu (50\% of minimum expected
        $|\Delta I_2|_{\rm SLG}$; consistent with
        IEC~60255-181~\cite{IEC_60255_181})
\end{itemize}

\subsection{Security for balanced conditions}

For a symmetric 3-phase fault or healthy balanced line, $|\Delta I_2| \approx 0$.
The 87LN element does not trip.  Natural 3-phase load imbalance yields
$|\Delta I_2| \approx 0.005$\,pu, safely below $I_{2,\rm thr} = 0.06$\,pu
(12$\times$ margin).  No false trips occur in the no-fault study~\cite{IEEE_C37_243}.

\section{Fundamental IBR Protection Limitation}
\label{sec:limitation}

The four 3PH cases missed at $k_{\rm ibr} < 0.12$\,pu represent a
well-documented limitation of line differential protection in
IBR-dominated networks~\cite{Hooshyar2019,Plet2011}:
\begin{enumerate}
  \item The fault current is determined by the IBR current controller,
        not by the system impedance.
  \item For a symmetric 3-phase fault the IBR injects $k_{\rm ibr}$ pu
        in positive sequence with \emph{zero} negative- or zero-sequence
        current.
  \item The differential is bounded by $k_{\rm ibr}$, which is below
        the protection threshold.
\end{enumerate}

\noindent \textbf{Backup protection for these cases:}
\begin{itemize}
  \item \textbf{87B bus differential (TR-14)}: bus protection detects the
        fault from the bus side — not affected by line-side IBR limiting.
  \item \textbf{21 distance relay Zone~1 (TR-18)}: impedance-based;
        detects impedance collapse at the relay point even with reduced
        current magnitude.
  \item \textbf{TR-23 (planned)}: IBR-aware distance element that uses
        voltage depression and impedance trajectory rather than current
        magnitude for primary detection.
\end{itemize}

The SAMBP three-function suite (87B + 87L/87LN + 21) therefore provides
complete coverage for symmetric 3PH IBR faults through backup; the
87LN closes the gap for asymmetric faults.

    \midrule
    \textbf{Recommended}: $I_{2,\rm thr} = 0.06$\,pu & & \\

  \end{tabular}

The recommended threshold $I_{2,\rm thr} = 0.06$\,pu provides a $2\times$
margin above the minimum SLG signal and a $12\times$ margin above the
natural imbalance floor.  For IEC~60255-181 compliance the negative-sequence
element should also include a definite-time delay of 0\,ms (instantaneous)
for zone-1 equivalent reach, with the delay to be set per the
coordination study~\cite{IEC_60255_181,Stevenson1994}.

\section{Conclusions}
\label{sec:conclusions}

\begin{enumerate}
  \item \textbf{5 additional SLG faults recovered}: TR-22 improves
        selectivity from 12/21 (baseline) to \textbf{17/21} by recovering all
        IBR-limited SLG cases via the negative-sequence differential.
  \item \textbf{SLG detection: 7/7 (100\%)}: $|\Delta I_2| = 0.12$\,pu
        exceeds $I_{2,\rm thr} = 0.06$\,pu regardless of IBR current
        limit in the range 0.08--0.20\,pu.
  \item \textbf{Security maintained}: healthy-line false-trip risk is
        negligible ($|\Delta I_2|_{\rm imbal} = 0.005$\,pu, $12\times$
        below threshold).
  \item \textbf{3PH symmetric fault limitation}: 4 cases with
        $k_{\rm ibr} < 0.12$\,pu remain undetectable by both 87L and 87LN
        — a fundamental IBR protection limitation.  Backup: 87B (TR-14)
        or 21 Zone~1 (TR-18).
  \item \textbf{Computational cost}: one additional DFT extraction per
        phase per cycle (shared with the LM estimator DFT) and one
        complex symmetrical-component transform — negligible overhead.
\end{enumerate}

\subsection{Future Work}

\begin{enumerate}
  \item \textbf{TR-23: IBR-aware 87L using voltage-supervised distance} ---
        for symmetric 3PH faults under heavy IBR current limiting, use
        terminal voltage depression as the primary fault indicator rather
        than current magnitude.
  \item \textbf{Zero-sequence 87LN0}: for solidly earthed systems add a
        zero-sequence differential ($|\Delta I_0|$) element; this provides
        an additional discriminant for earth faults that complements the
        negative-sequence element.
  \item \textbf{IBR negative-sequence injection strategies}: some modern
        IBRs deliberately inject negative-sequence current during asymmetric
        faults (ENTSO-E~\cite{ENTSO_RfG} Article~22).  Characterise the
        effect on the 87LN threshold when $I_2$ contributions from both
        ends are controlled quantities rather than purely network-determined.
  \item \textbf{Hardware-in-the-loop validation}: test 87LN on a
        real-time digital simulator with IBR hardware-in-the-loop to
        validate the sequence extraction latency under realistic inverter
        control dynamics.
\end{enumerate}
